HTML5 Semántico y CSS3

Estándares de estructuración web y modelo de cajas para maquetación.

El Modelo de Caja (Box Model)

Cada elemento maquetado en HTML es calculado por el navegador como una caja rectangular compuesta por contenido, padding, borde y margen.

CSS3 Resets Globales 
/* Garantiza que el padding y border no alteren el ancho total asignado */
* {
    box-sizing: border-box;
    margin: 0;
    padding: 0;
}
