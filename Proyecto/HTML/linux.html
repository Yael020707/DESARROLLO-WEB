Navegación de directorios y administración de archivos del sistema.

Jerarquía del Sistema de Archivos

Comandos Esenciales

Comando Descripción Técnica Ejemplo de Uso
pwd Muestra la ruta absoluta del directorio de trabajo actual. pwd
ls -la Lista el contenido del directorio incluyendo permisos y archivos ocultos. ls -la /var/www
mkdir Crea una nueva carpeta dentro del directorio especificado. mkdir mi-proyecto
chmod Modifica los permisos de lectura, escritura y ejecución de un archivo. chmod 755 script.sh
